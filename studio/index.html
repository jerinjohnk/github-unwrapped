Unwrapped Studio

Make a GitHub year-in-review video for any date range (in IST). Runs on this computer; your key is never saved.

1GitHub key ▶

A personal access token from github.com/settings/tokens (no scopes needed for public data). It stays in this tab's memory, is sent only to this local server for the GitHub requests, and is not written to disk.

2GitHub user ▶

Whose year to unwrap.

3Date range ▶

Every number in the video is filtered to this range: contributions, the contribution grid, longest streak, pull requests, issues, stars, commits (top day and hour) and languages. Dates and times are in IST (UTC+05:30): a range runs from midnight to midnight IST. GitHub limits a range to one year.

4Stats ▶
5Video ▶

Pick a rocket and generate. The first render prepares the project and takes a few minutes; later ones take about 1–2 minutes. Videos are cached in .local-data/renders/.
