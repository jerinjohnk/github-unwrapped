Unwrapped Studio

Make a GitHub or Bitbucket year-in-review video for any date range (in IST). Runs on this computer; your keys are never saved.

1Account ▶

A GitHub personal access token from github.com/settings/tokens (no scopes needed for public data; to include private repositories, give it read access to them: a fine-grained token with Contents, Pull requests and Issues read, or a classic token with the repo scope).

Whose year to unwrap:

The video is for the account that owns the token, across all its Bitbucket workspaces. Create a token at id.atlassian.com → Security → API tokens: Create API token with scopes, choose Bitbucket and tick the read scopes .

Keys stay in this tab's memory, are sent only to this local server for the API requests, and are not written to disk.

2Date range ▶

Every number in the video is filtered to this range: contributions, the contribution grid, longest streak, pull requests, issues (GitHub), stars (GitHub), commits (top day and hour) and languages. Dates and times are in IST (UTC+05:30): a range runs from midnight to midnight IST. A range can be at most one year.

3Repositories ▶

Choose which repositories count. Your commits and languages come from your pull requests; in a repository without pull requests by you, only the pull requests you approved count. Skip this step to use every repository with your pull requests.
